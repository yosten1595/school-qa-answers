# Q7. HTTPメソッド

## 問題

このアプリのAPIでは以下を使っています。

- GET
- POST
- PUT
- DELETE
- PATCH

これらの「HTTPメソッド」とは何ですか？

日常生活の例えで、それぞれの違いを説明してください。

## 回答

「HTTPメソッド」とは、リクエストの中で、サーバー上のデータに対して何をしたいかを伝える種類の指定です。同じ宛先に送る場合でも、メソッドによってサーバーは「取得する」「作成する」「置き換える」「一部を修正する」「削除する」を区別します。

日常生活の例えでは、住所録(連絡帳)の操作にあたります。

- GET: 住所録を開いて、田中さんの電話番号を見ます。見るだけで、中身は変わりません。画面に表示するためにデータを読むときに使います。
- POST: 住所録に、新しい人を1人書き足します。新しいデータを登録するときに使います。
- PUT: 田中さんのページを、名前・電話番号・住所の全項目を書き直して、丸ごと差し替えます。編集画面の全項目をまとめて保存するときに使います。
- PATCH: 田中さんのページのうち、電話番号だけを書き換えます。他の項目はそのままです。1つの項目だけを変えたいときに使います。
- DELETE: 田中さんのページを、住所録から消します。データを削除するときに使います。

PUT と PATCH はどちらも既存のデータを変えるメソッドですが、PUT は全項目を送って全体を置き換え、PATCH は変えたい項目だけを送る点が違います。

5つのメソッドは、データに対する「取得・作成・丸ごと置き換え・一部修正・削除」という操作の違いを示すものだと理解しました。

## 理解のメモ

- HTTP メソッド = リクエストの中で、データに対する操作の種類を伝える指定。
- GET = 取得、POST = 作成、PUT = 丸ごと置き換え、PATCH = 一部修正、DELETE = 削除。
- GET はデータを変更しないので、何度送っても安全。
- PUT は全項目を送るので、送り忘れた項目が空になる危険がある。1項目だけの変更には PATCH が向く。
- 例え: 住所録の「見る・書き足す・ページを丸ごと差し替える・1項目だけ書き換える・ページを消す」。
- 回答に例えを入れたのは、問題が日常生活の例えを求めているため(この問題だけの扱い)。
