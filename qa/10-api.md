# Q10. APIとは

## 問題

このアプリではフロントエンドがバックエンドのAPIを呼び出してデータを取得しています。

- APIとは何ですか？
- なぜ直接データベースにアクセスしないのですか？

## 回答

「API」は Application Programming Interface の略で、プログラム同士が依頼をやり取りするための窓口です。このアプリでは、フロントエンドがバックエンドの API にリクエストを送り、バックエンドがデータを JSON でレスポンスとして返します。窓口ごとに、宛先と HTTP メソッドが決まっています。

フロントエンドが直接データベースにアクセスしないのは、次の理由からです。

- 安全のため: フロントエンドのプログラムは利用者のブラウザに配られるので、中身を見られます。データベースへの接続情報を入れると、誰でも盗めてしまいます。
- 勝手な操作を防ぐため: データベースに直接つなげると、他人のデータを見たり、全部消したりできてしまいます。API を挟めば、バックエンドが、その操作をしてよいかを確認できます。
- ルールを守らせるため: 入力のチェックなど、データの決まりごとを、バックエンドが1か所で守らせられます。
- 変更に強くするため: データベースの作りを変えても、API の窓口が同じなら、フロントエンドは変更せずに済みます。

API は、プログラム同士が決まった窓口を通して依頼をやり取りするためのもので、データベースにはバックエンドだけが触れるようにして安全と決まりごとを守るために使われていると理解しました。

## 理解のメモ

- API = Application Programming Interface。プログラム同士が依頼をやり取りするための窓口。
- このアプリの流れは、フロントエンドが API にリクエストを送り、バックエンドが JSON でレスポンスを返す。
- 直接データベースにアクセスしない理由は、安全、勝手な操作の防止、決まりごとの一元管理、変更に強くすること。
- フロントエンドのプログラムはブラウザに配られるため、中に入れた情報は利用者に見られる。
