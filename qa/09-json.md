# Q9. JSONとは

## 問題

フロントエンドとバックエンド間でデータをやり取りする際に「JSON」という形式が使われています。

- JSONとは何ですか？
- なぜ広く使われていますか？

## 回答

「JSON」は JavaScript Object Notation の略で、データを「項目名と値」の組み合わせで表すための、文字だけでできたデータ形式です。たとえば `{"id": 1, "title": "牛乳を買う", "done": false}` のように書きます。値には、文字列、数値、真偽値(`true` / `false`)、`null`、値を並べたリストなどを使えます。

JSON が広く使われているのは、次の理由からです。

- 読みやすい: 文字だけでできているので、人間が見て中身がすぐ分かります。
- 軽い: 余計な記号が少なく、同じ役割の XML という形式より短く書けるため、データの量が小さく済みます。
- 言語に依存しない: JavaScript、Java、Python など、どの言語でも読み書きできます。フロントエンドとバックエンドで言語が違っていても、データをやり取りできます。
- JavaScript と相性がよい: JavaScript のオブジェクトの書き方が元になっているので、ブラウザ側で簡単に扱えます。

JSON は、フロントエンドとバックエンドが共通の書式でデータをやり取りするための、項目名と値で表すデータ形式だと理解しました。

## 理解のメモ

- JSON = JavaScript Object Notation。項目名と値でデータを表す、文字だけのデータ形式。
- 広く使われる理由は、読みやすい、軽い、言語に依存しない、JavaScript と相性がよい、の4つ。
- リクエストやレスポンスの本文に JSON が入っていることがよくある。
