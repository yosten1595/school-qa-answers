# Q6. リクエストとレスポンス

## 問題

Webにおける「リクエスト」と「レスポンス」の関係を、日常生活の例えを使って説明してください。

## 回答

「リクエスト」は、ブラウザが Web サーバーに「このページをください」と送る依頼です。「レスポンス」は、サーバーがその依頼に応えて、ページのデータなどを返す返事です。通信は必ずリクエストが先で、レスポンスはそのあとです。サーバーが勝手にデータを送ってくることはなく、1つのリクエストに対して1つのレスポンスが返ります。

日常生活の例えでは、レストランでの注文にあたります。客がブラウザ、店員がサーバーです。客が「カレーをください」と注文するのが「リクエスト」で、店員が料理を用意して客の席に運ぶのが「レスポンス」です。注文がなければ料理は来ませんし、1つの注文に対して1つの料理が届きます。該当する料理がなければ、店員は「品切れです」と返します。Web でも、該当するページがないときは、エラーを知らせるレスポンスが返ります。

「リクエスト」はブラウザが先に出す依頼で、「レスポンス」はそれに対するサーバーの返事であり、必ず依頼が先、返事があとの関係だと理解しました。

## 理解のメモ

- リクエスト = ブラウザからサーバーへの依頼。レスポンス = サーバーからブラウザへの返事。
- 順番は、必ずリクエストが先、レスポンスがあと。1つのリクエストに1つのレスポンス。
- 例え: 客の注文 = リクエスト、店員が運ぶ料理 = レスポンス、品切れの返事 = エラーのレスポンス。
- 回答に例えを入れたのは、問題が日常生活の例えを求めているため(この問題だけの扱い)。
