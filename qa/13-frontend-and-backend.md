# Q13. フロントエンドとバックエンド

## 問題

「フロントエンド」と「バックエンド」の違いを説明してください。

このアプリではそれぞれ何を担当していますか？

## 回答

「フロントエンド」は、利用者が直接見て触る部分です。画面の表示や、ボタン・フォームなどの操作の受け付けを担当し、利用者のブラウザの中で動きます。「バックエンド」は、利用者からは見えない裏側の部分です。データの保存と取得、入力のチェック、ルールに沿った処理を担当し、サーバー側で動いてデータベースとやり取りします。

このアプリはトレロ風のアプリで、それぞれ次のものを担当しています。

- フロントエンド(5173): ボード、リスト、カードの画面を表示します。カードの追加、編集、ドラッグでの移動といった利用者の操作を受け付け、操作に応じてバックエンドの API にリクエストを出します。返ってきたデータで画面を更新します。
- バックエンド(8080): API でリクエストを受け、入力をチェックし、データベースにボード、リスト、カードを保存・取得します。結果は JSON のレスポンスで返します。

たとえば、カードを別のリストにドラッグして動かす場合は、次の流れになります。フロントエンドがドラッグ操作を受け付け、バックエンドの API にリクエストを出します。バックエンドがデータベースのカードの所属リストを書き換え、結果を JSON で返します。フロントエンドがそれを受け取って、画面を更新します。

フロントエンドは利用者が見て触る画面を、バックエンドは裏側でデータと処理を担当し、両者が API でやり取りすることでアプリが動いていると理解しました。

## 理解のメモ

- フロントエンド = 利用者が見て触る部分(ブラウザの中で動く)。バックエンド = 裏側でデータと処理を担当する部分(サーバー側で動く)。
- このアプリはトレロ風で、フロントエンドは画面の表示と操作の受け付け、バックエンドはデータの保存・取得と入力のチェックを担当する。
- 両者は API で、リクエストとレスポンスをやり取りする。
- 例: カードの移動は、ドラッグ操作 → API にリクエスト → データベースを書き換え → JSON で返事 → 画面を更新、という流れになる。
