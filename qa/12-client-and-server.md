# Q12. クライアントとサーバー

## 問題

「クライアント」と「サーバー」とは何ですか？

このアプリの構成の中で、それぞれどれがクライアントでどれがサーバーですか？

- ブラウザ
- バックエンド
- データベース

## 回答

「クライアント」は、リクエストを出す側です。「サーバー」は、リクエストを受けて、レスポンスを返す側です。どちらも特定の機械や製品の名前ではなく、リクエストとレスポンスのやり取りにおける役割の名前です。

このアプリの構成では、次のようになります。

- ブラウザ: クライアントです。バックエンドにリクエストを出します。
- バックエンド: サーバーです。ブラウザからのリクエストを受けて、レスポンスを返します。
- データベース: サーバーです。バックエンドからのリクエストを受けて、データを返します。

ただし、バックエンドは、やり取りの相手によって両方の役割を持ちます。ブラウザから見ると、バックエンドはサーバーです。データベースから見ると、バックエンドはデータを頼む側なので、クライアントです。

クライアントとサーバーは、依頼する側と応える側という役割の呼び名であり、同じものでも相手によって役割が変わると理解しました。

## 理解のメモ

- クライアント = リクエストを出す側。サーバー = リクエストを受けてレスポンスを返す側。
- どちらも機械や製品の名前ではなく、役割の名前。
- ブラウザ = クライアント、バックエンド = サーバー、データベース = サーバー。
- バックエンドは、ブラウザに対してはサーバー、データベースに対してはクライアントの役割を持つ。
