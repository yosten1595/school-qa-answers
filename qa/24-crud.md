# Q24. CRUD操作

## 問題

CRUDとは何の略ですか？

それぞれがこのアプリのどの機能に対応するか説明してください。

- Create
- Read
- Update
- Delete

## 回答

CRUD は、データに対する4つの基本操作である Create(作成)、Read(読み取り)、Update(更新)、Delete(削除)の頭文字です。

このアプリ(トレロ風アプリ)の機能との対応は、カード(`tasks`)を例にすると、次のとおりです。ボードやリストも同じ形で当てはまります。

- Create: 新しいカードを作る機能です。HTTP メソッドは POST で、データベースでは行を1つ追加します。
- Read: カードの一覧を表示したり、1枚のカードを開いたりする機能です。HTTP メソッドは GET で、データベースでは行を取り出します。
- Update: カードのタイトルを編集したり、別のリストへ動かしたりする機能です。HTTP メソッドは PUT(丸ごと置き換え)または PATCH(一部だけ修正)で、データベースでは行の値を書き換えます。
- Delete: カードを削除する機能です。HTTP メソッドは DELETE で、データベースでは行を消します。

CRUD と HTTP メソッドは、対応はしますが、別のものです。CRUD はデータに対して何をしたいかという操作の種類で、データベースなどあらゆる層で使う言葉です。HTTP メソッドは、その操作を API に伝えるためのリクエストの指定で、HTTP 通信の場面だけで使います。また、CRUD は4つですが、Update に PUT と PATCH の2つが当たるため、メソッドは5つあります。この対応は一般的なものです。

CRUD は、作成・読み取り・更新・削除というデータの4つの基本操作であり、アプリの機能はその組み合わせでできていて、通信では HTTP メソッド、データベースでは行の操作に対応すると理解しました。

## 理解のメモ

- CRUD = Create(作成)、Read(読み取り)、Update(更新)、Delete(削除)。データに対する4つの基本操作。
- 対応は、Create = POST、Read = GET、Update = PUT / PATCH、Delete = DELETE。データベースでは、行の追加・取り出し・書き換え・削除。
- CRUD は「やりたいこと」、HTTP メソッドは「それを API に伝える言葉」。数も使う場面も違う(CRUD は4つで、あらゆる層で使う。メソッドは5つで、HTTP 通信だけで使う)。
- トレロ風アプリでは、カードの作成・表示・編集や移動・削除が、それぞれ Create・Read・Update・Delete に当たる。
- この対応は一般的なもので、このアプリの実際のメソッドの使い方は確認していない。
