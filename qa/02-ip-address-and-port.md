# Q2. IPアドレスとポート番号

## 問題

このプロジェクトではフロントエンドを `localhost:5173`、バックエンドを `localhost:8080` で起動しています。

- `localhost`とは何を指しますか？
- `:5173` や `:8080` のようなポート番号はなぜ必要ですか？

## 回答

`localhost` は、いま操作している自分のコンピュータ自身を指す名前です。実体は IP アドレスの `127.0.0.1` で、このアドレス宛の通信は外部のネットワークに出ず、自分のコンピュータの中だけで完結します。

ポート番号が必要なのは、IP アドレスだけでは「どのコンピュータか」までしか特定できないからです。1台のコンピュータの中では複数のプログラムが同時に通信を待ち受けているため、通信をどのプログラムに渡すかを区別する番号が要ります。このプロジェクトでは、同じ `localhost` の上で `:5173` がフロントエンド、`:8080` がバックエンドに対応しています。ポート番号が違うので、2つを同時に起動できます。

IP アドレスは通信相手のコンピュータを、ポート番号はそのコンピュータの中のプログラムを特定するもので、両方がそろって初めて通信先が決まると理解しました。

## 理解のメモ

- `localhost` = 自分自身のコンピュータ(`127.0.0.1`)。
- IP アドレスはコンピュータを、ポート番号はその中のプログラムを特定する。
- 同じポート番号は同時に使えない。
