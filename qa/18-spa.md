# Q18. SPA（シングルページアプリケーション）

## 問題

このアプリはReactで作られたSPAです。

従来のWebサイト（ページ遷移するもの）と何が違いますか？

## 回答

従来のWebサイトは、リンクやボタンをクリックするたびに、ブラウザがサーバーにリクエストを送り、サーバーが作ったページ全体の HTML を返します。ブラウザは今のページを捨てて、新しいページに丸ごと入れ替えます。

SPA は、最初に1回だけアプリ全体のプログラム(HTML と JavaScript)を読み込みます。ページ(HTML)が実質1枚だけなので、シングルページといいます。そのあとは、ページを丸ごと入れ替えません。操作に応じて、フロントエンドがバックエンドの API に必要なデータだけを非同期で頼み、JSON で返ってきたデータを使って、画面の変わる部分だけを書き換えます。

違いをまとめると、次のようになります。

- クリックしたとき: 従来は、ページ全体をサーバーから取り直します。SPA は、必要なデータだけを取り、画面の一部を書き換えます。
- サーバーから届くもの: 従来は、完成した HTML のページです。SPA は、データ(JSON)です。
- 画面の切り替わり: 従来は、ページが丸ごと入れ替わります。SPA は、一部だけが変わり、なめらかです。

このアプリ(トレロ風アプリ)では、カードを追加したり、ドラッグで動かしたりしても、ページ全体は入れ替わらず、変わった部分だけが書き換わります。従来の方式だと、カードを動かすたびにページ全体が読み込み直しになり、使いにくくなります。

React は、データが変わったときに画面の必要な部分だけを書き換える仕組みを提供する、SPA を作るための道具です。

SPA の長所は、画面の切り替えがなめらかで、アプリのように使えることです。短所は、最初に読み込むプログラムが大きく、最初の表示が遅くなることがある点です。

SPA は、最初に1回だけ読み込んだあと、必要なデータだけを API で取って画面の一部を書き換えるものであり、ページ全体を入れ替える従来のWebサイトとは、そこが違うと理解しました。

## 理解のメモ

- 従来のWebサイト = 操作のたびに、ページ全体の HTML をサーバーから取り、ページを丸ごと入れ替える。
- SPA = 最初に1回アプリ全体を読み込み、あとは API で必要なデータ(JSON)だけを非同期で取り、画面の一部を書き換える。
- トレロ風アプリでは、カードの追加や移動で、ページ全体は入れ替わらず、変わった部分だけが変わる。
- React = SPA の画面を作るための道具(ライブラリ)。SPA は「作り方・動き方」の名前。
- 長所はなめらかな操作感、短所は最初の読み込みが大きく遅くなることがある点。
