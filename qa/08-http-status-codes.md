# Q8. HTTPステータスコード

## 問題

サーバーからの返事には「ステータスコード」という3桁の数字が含まれます。

以下のコードはそれぞれ何を意味しますか？

- 200
- 201
- 400
- 404
- 500

## 回答

「ステータスコード」は、リクエストの結果を伝える3桁の数字で、サーバーからのレスポンスに含まれます。最初の1桁で、2xx は成功、4xx はクライアント(リクエストを出した側)の問題、5xx はサーバー側の問題と、大まかな種類が分かります。

- 200(OK): リクエストが成功しました。
- 201(Created): リクエストが成功し、新しいデータが作成されました。POST でデータを新規作成したときなどに返ります。
- 400(Bad Request): リクエストの内容が不正で、サーバーが処理できません。
- 404(Not Found): 指定された宛先のデータやページが見つかりません。
- 500(Internal Server Error): サーバーの内部で想定外のエラーが起きました。

200 と 201 はどちらも成功ですが、201 は新しいデータが作られた場合に返る点が違います。400 と 404 はリクエスト側に原因があり、500 はサーバー側に原因があります。

ステータスコードは、リクエストの結果と、問題があれば原因がどちら側にあるかを、数字で伝えるものだと理解しました。

## 理解のメモ

- ステータスコード = レスポンスに含まれる、リクエストの結果を表す3桁の数字。
- 最初の1桁の意味は、2xx = 成功、4xx = クライアント側の問題、5xx = サーバー側の問題。
- 200 = 成功、201 = 成功して新規作成、400 = リクエストが不正、404 = 見つからない、500 = サーバー内部のエラー。
- エラーの調査では、まず最初の1桁で、原因がリクエスト側かサーバー側かを切り分ける。
