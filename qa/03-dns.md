# Q3. DNS

## 問題

ブラウザのアドレスバーに

`https://www.example.com`

と入力してからページが表示されるまでに、DNSはどのような役割を果たしますか？

## 回答

DNS は、ドメイン名を IP アドレスに変換する役割を果たします。この変換を名前解決といいます。

ブラウザが実際に通信するには、相手のコンピュータの IP アドレスが必要です。人間が扱いやすいのは `www.example.com` のような名前ですが、通信そのものは名前ではなく IP アドレスで行われます。

そのため、`https://www.example.com` を入力すると、ブラウザはまず DNS に `www.example.com` の IP アドレスを問い合わせ、DNS が IP アドレスを返します。ブラウザはその IP アドレス宛に HTTPS で接続してページを要求し、Web サーバーが返したデータをブラウザが表示します。DNS が担うのは IP アドレスを調べて返す段階までで、ページのデータを届けるのは Web サーバーです。

DNS は、入力した名前から通信先の IP アドレスを調べて、ブラウザが Web サーバーに接続できるようにする仕組みであると理解しました。

## 理解のメモ

- DNS = ドメイン名を IP アドレスに変換する仕組み(名前解決)。
- 通信は名前ではなく IP アドレスで行われるため、先に名前解決が要る。
- DNS はページを届けない。ページを返すのは Web サーバー。
- 流れは、入力 → DNS で IP アドレスを取得 → Web サーバーに HTTPS で接続 → ページを受け取って表示。
