# Q5. HTTPとHTTPSの違い

## 問題

HTTPとHTTPSの違いは何ですか？

なぜ現在のWebサイトはほぼすべてHTTPSを使用していますか？

## 回答

HTTPS は、HTTP の通信を TLS で暗号化したものです。要求と返事の形式という通信の決まりごとは HTTP と同じで、違いはやり取りの途中が暗号化されているかどうかです。HTTP は暗号化されていないため、通信の途中で内容を見られたり書き換えられたりするおそれがあります。HTTPS は、通信の盗み見と改ざんを防ぎ、証明書によって通信相手が本物のサイトかどうかも確認できます。

現在のWebサイトがほぼすべて HTTPS を使用しているのは、HTTP のままだと次の危険があるからです。

- 盗み見: パスワードやクレジットカード番号などが、通信の途中で見られるおそれがある。
- 改ざん: 通信の途中で内容を書き換えられ、偽の画面や広告を差し込まれるおそれがある。
- なりすまし: 偽のサイトと本物のサイトを区別できず、利用者が気づけない。

さらに、ブラウザが HTTP のサイトに「保護されていない通信」と警告を出すようになったこと、無料で証明書を取得できる仕組みが広まって HTTPS への切り替えの負担が下がったことも、普及を後押ししています。

HTTPS は、HTTP を暗号化して盗み見・改ざん・なりすましを防ぐものであり、その危険があるため現在はほぼすべてのサイトが使っていると理解しました。

## 理解のメモ

- HTTPS = HTTP + TLS による暗号化。通信の決まりごとは HTTP と同じ。
- HTTPS の働きは、盗み見の防止、改ざんの防止、通信相手の確認(証明書)の3つ。
- HTTPS が守るのは通信であり、サイトの運営者が信頼できるかどうかまでは保証しない。
- ほぼすべてのサイトが HTTPS なのは、HTTP の危険に加えて、ブラウザの警告と無料の証明書も背景にある。
